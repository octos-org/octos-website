# octos-website

Source for [www.octosai.org](https://www.octosai.org), the official Octos
website. Built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Official deployments

These public deployments are operated by the octos-org maintainers:

- [www.octosai.org](https://www.octosai.org) — this site
- [learn.pitun.cc](https://learn.pitun.cc) — [Octos Learn](https://github.com/octos-org/octos-learn), the AI learning canvas product

## Develop

```bash
npm ci
npm run dev
```

`npm run build` produces the static site in `dist/`; `npm run preview` serves
the production build locally.
